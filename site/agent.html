Sixty-second path

Add KNOBE to your agent.

Your agent can create, verify and transform sealed knowledge files. Install the server, paste the prompt, and you will have a real .knobe.md with a verifiable seal in about a minute.

1. Install

claude mcp add knobe -- npx -y knobe-mcp

Requires Node 20 or later. The package is knobe-mcp on npm; it runs locally, makes no network requests and keeps no state between calls.

{
  "mcpServers": {
    "knobe": {
      "command": "npx",
      "args": ["-y", "knobe-mcp"]
    }
  }
}

Add this block to your client's MCP configuration file. The same block works in Windsurf and most other MCP clients.

Draft here, seal in Studio. A model can write the words and the record; it cannot compute the seal. Ask your assistant to draft the title, a short summary, the attribution and the use conditions, then paste them into Studio and press Seal. Studio runs in your browser and uploads nothing.

2. Paste the prompt

You have the KNOBE MCP server. Create a sealed .knobe.md from the following.

Title: [your title]
Author: [your name]
Content: [paste or describe]
License: [CC BY 4.0 or your choice]
AI involvement: [none, or describe what the AI did]

Use the server's knobe_create tool to produce the file. Do not compute any hash yourself. Then verify the file with the server's knobe_verify tool and show me the verification result and the full file.

3. Read the result

  1. Install the server using the block for your tool.
  2. Paste the prompt and fill in the brackets.
  3. Read the verification result. It says whether the sealed record matches the file.
  4. Open the file in any editor. The top is readable; the bottom is the record and the seal.
A language model is not a verification environment. The seal is computed, never written.KNOBE white paper, section 5

That line is on this page because it is the most common early mistake. The model drafts the fields; the engine computes the hash. If an assistant ever offers to write the seal itself, decline.
