A file format, a seal, a verifier. That is the whole surface.

A .knobe.md is as portable as any Markdown file: plain text, interoperable, human- and machine-readable, accessible by construction. What is new is what travels inside it: a base64 JSON payload at the end of the file. The payload records attribution, transformation history, fidelity limits, use conditions and accessibility lineage, and carries a SHA-256 hash of itself. One engine, knobe-core.js, creates, verifies and transforms these files; everything else is a thin adapter over it. The MCP server gives any agent five tools. The spec is frozen at v1.0; nine core test vectors set the canonical-compatibility bar, and sixteen more probe hostile input or pin errata rulings. Sealing a first file does not require reading any of it first.
